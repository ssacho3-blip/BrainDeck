🚀 1. BrainDeck v5.5.0 — 5대 핵심 기억·학습 프레임 (Python ↔ JS ViewModel ↔ Android Kotlin 1:1 패리티)

단일 Clean Architecture 도메인에서 Python 백엔드(src/braindeck/domain/), Apple 웹어플(PWA viewmodel.js), Android 네이티브 앱(:domain Kotlin)이 100% 동일한 채점·힌트·스케줄링 결과를 보장합니다.

Frame 1 · 전 연령 학습자 프로파일 LearnerProfile v2

  • 🌱 Junior (초등 1~6): 앞면 ≤40자 / 뒷면 ≤60자, 일일 신규 10장·복습 50장, 목표기억률 0.85, 4지선다 기본(solveMode: "choice").
  • 🚀 Teen (중·고등 내신/수능): 앞면 ≤100자 / 뒷면 ≤150자, 일일 20/150장, 목표기억률 0.90, 적응형 풀이(adaptive).
  • 🎓 Adult/Pro (대학생·성인): 앞면 ≤220자 / 뒷면 ≤400자, 일일 25/150장, 백지 서술형 인출 우선.
  • 🔒 아동 보호 하드락: Junior 모드는 외부 클라우드 비전/LLM 잠금(cloud_vision_locked = 1) 및 자기평가 Easy(4) 버튼 전역 비활성화.

Frame 2 · 1-Card 1-Mode 적응형 풀이 resolveCardSolveMode

  • 신규 카드 (reps == 0, state == 'new'): 처음 보는 개념은 4지선다 객관식(choice)으로 출제해 초기 진입 장벽과 포기율을 낮춤.
  • 복습 카드 (reps >= 1, state == 'review'): 한 번 이상 학습한 카드는 자동으로 주관식 타이핑 인출(typing)로 승격하여 진짜 장기기억 회상 유도.
  • 수동 오버라이드 지원: 사용자가 flip(암기장 넘기기), choice, typing 모드를 명시적으로 고정할 수도 있음.

Frame 3 · 객관적 채점 가드 & 정밀 채점 EvidenceRatingGuard

  • 정답 공개 전 평점 잠금 (pre_reveal): 뒷면 정답을 확인하기 전에는 1~4 평점 버튼 클릭 원천 차단.
  • 오답 / '모름' 클릭 시 Again(1) 고정: 객관식 오답, 주관식 UNKNOWN, 또는 모름 클릭 시 Again(1)만 활성화.
  • 힌트 사용 시 Hard(2) 상한 클램프: 힌트(hint_step >= 1)를 열람한 뒤 맞힌 카드는 Good(3)·Easy(4)를 잠그고 최대 Hard(2)로 제한.
  • 괄호 병기 제외 핵심 정답 100점 판정: 훈민정음 (訓民正音), 강화도 조약 (1876), 소개하다 (동사)에서 훈민정음, 강화도 조약, 소개하다만 입력해도 100점(EXACT) 판정 및 2단계 초성/글자수 힌트와 정확히 일치.

Frame 4 · 형제 카드 자동 유예 Sibling Burying

  • 동일 개념 태그(concept:<id>)에서 파생된 난이도별 카드(Lv.1 기초 재인, Lv.2 문맥 빈칸, Lv.3 백지 인출)가 한 세션에 동시에 등장해 앞 카드가 뒷 카드의 스포일러가 되는 현상 방지.
  • deduplicate_session_siblings가 세션 큐 구성 시 동일 concept:<id> 그룹당 가장 우선순위가 높은 단 1장의 카드만 남기고 나머지는 자동 유예.

Frame 5 · Apple Standalone 오프라인 엔진 createStandaloneEngine

  • 아이폰·아이패드·맥 Safari에서 백엔드 Python 서버 없이도 100% 동작하는 클라이언트 내장형 엔진(viewmodel.js + BrainDeckLocalVault).
  • 오프라인 상태에서 ① 내장 교과서/한자 카탈로그 조회, ② 다중 과목 통합 시험대비 덱 생성(buildCombinedExamDeck), ③ 스마트 텍스트 덱 추출(buildSmartTextDeck), ④ FSRS-5 복습 스케줄링 완벽 수행.

다중 과목 통합 시험대비 덱 & 인터리빙 Anti-Streak ≤ 2

  • 중간·기말고사 대비 시 여러 과목(예: 중1 영어 1단원 + 8급 한자 + 역사 연표)을 하나의 시험대비 덱으로 묶어 생성(build_combined_exam_deck).
  • 과목별 카드 수가 6 : 2 : 2처럼 불균형해도 Greedy Largest-Bucket-First Anti-Streak(<= 2) 알고리즘(interleave_study_cards)이 동일 과목이 3연속 이상 나오지 않도록 교차 섞기 수행.
💡 기존 플래시카드 대비 핵심 차별점 요약: SM-2의 Ease Hell을 FSRS-5 (DSR 19-파라미터 평균회귀 모델)로 해결해 복습량을 30% 절감하고, 휴가 후 밀린 카드는 Smart Backlog Decompressor(plan_backlog_decompression)로 평탄화하며, 8번 이상 틀리는 거머리 카드는 AI Leech 원자 분할기(decompose_leech_card)가 2~3장의 단일 개념 마이크로 카드로 자동 쪼개고 부모 카드를 자동 일시중지(suspended=1)합니다.
