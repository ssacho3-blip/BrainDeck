## 1️⃣ [Model 1] Claude Opus 5.5 — 인지학습 도메인 & 프로덕트 아키텍트 관점

### (A) Claude Opus 5.5의 경쟁사 REA 역공학 핵심 진단
1. **지식 고립(Context Isolation) 문제 (`RemNote` & `SuperMemo SM-18` 비교)**:
   - BrainDeck v6.0에서 목차/헤더가 문제로 나오는 버그는 막았으나, 정작 걸러낸 **목차/장/절(Chapter/Section) 제목은 버리지 말고 카드의 상위 맥락 브레드크럼(`Breadcrumb Context Header`) 자산(Resource)**으로 승격해야 한다. RemNote가 강력한 이유는 카드 앞면 상단에 `[제2장 열역학 > 2.3 엔트로피]` 계층 경로가 항상 표시되어, 짧은 질문이라도 어느 맥락의 질문인지 즉시 파악되기 때문이다.
2. **거머리 카드(Leech)의 근본 원인은 '선수 개념 결손' (`WaniKani` 비교)**:
   - WaniKani는 부수(Radical)를 `Guru` 등급으로 마스터하기 전까지 한자(Kanji)를 절대 출제하지 않는다. 반면 현재 BrainDeck v6.0은 1,000장 덱에서 기초 정의 카드(`Lv.1`)를 아직 틀리고 있는데도 그 정의를 전제로 한 심화 추론 카드(`Lv.3~4`)가 당일 큐에 함께 출제될 수 있다.
3. **'진척률(%)'과 '시험장 회상 확률(%)'의 괴리 (`A-SRS FSRS-5` & `SuperMemo` 비교)**:
   - v6.0의 `Coverage %(진도율)`와 `Mastery %(가중 숙련도)`는 훌륭한 출발점이지만, 사용자가 진짜 알고 싶은 것은 **"내가 시험 치는 D-Day 아침 9시에 이 1,000장 중 몇 %를 실제로 기억해낼 수 있는가(Expected Exam-Day Retrievability)"**이다.
4. **단방향 암기에서 '양방향/다각도 인출(Multi-Faceted Note)'로의 전환 (`A-SRS` 비교)**:
   - 하나의 핵심 개념(`Note`)은 ① `용어 ➔ 정의`, ② `정의 ➔ 용어`, ③ `오개념 반례 판별`이라는 3개의 파생 카드(`Facet Cards`)를 가질 수 있어야 하며, 같은 날 남매 카드(Sibling Cards)가 동시에 나와 힌트를 주는 현상(`Sibling Burying`)이 정교화되어야 한다.

### (B) [Claude Opus 5.5] 기구현 기능(BrainDeck v6.0) 고도화 개선안 리스트 (Top 6)
| # | 기구현 기능 (BrainDeck v6.0) | 현재 한계점 | Claude Opus 5.5의 고도화 개선안 (`Better Upgrade`) |

### (C) [Claude Opus 5.5] 신규 구현 추천 기능 리스트 (Top 6)
1. **교과서/PDF 점진적 독해 파이프라인 (`Incremental Reading Lite`)**:
   - 긴 PDF나 사진 20장을 한 번에 500장 카드로 폭탄 생성하지 않고, **오늘 읽을 발췌문(Extract) 5개**만 먼저 보여준 뒤 읽은 문단에서만 즉시 3~5장씩 카드를 부화(Hatch)시키는 SuperMemo식 점진적 독해 루프.
2. **선수 개념 해금 그래프 (`WaniKani-style Prerequisite Gate`)**:
   - 1,000장 덱을 **Section 1~20 (각 50장 구간)** 또는 **`Lv.1 기초 용어 ➔ Lv.2 원리 ➔ Lv.3 응용`** DAG로 묶어, 앞 구간의 진도율이 70%에 도달할 때마다 다음 구간이 자동 해금되는 도장깨기 구조.
3. **의미 간섭 대조 카드 자동 생성기 (`Contrastive Twin-Card Generator`)**:
   - 객관식/주관식에서 사용자가 자주 헷갈리는 두 개념(`A` 문제에서 `B` 선지를 고름)을 감지하면, 즉시 **`[혼동 주의] A vs B 결정적 차이점 1가지`** 비교 대조 카드를 자동 생성하여 세션에 삽입.
4. **원문 하이라이트 역추적 뷰어 (`Source Anchor Reverse-Lookup`)**:
   - 학습 중 카드 우측 상단 `[📄 원문 보기]` 탭 시, 해당 카드가 추출된 원본 문서/노트의 정확히 그 문단(앞뒤 3문장 하이라이트)을 바텀시트로 즉시 팝업.
5. **핵심 키워드 루브릭 서술형 채점기 (`Rubric-Based Constructed Response`)**:
   - 한국 내신 서술형·자격증 실기 대비를 위해, 문장 전체가 글자 그대로 일치하지 않아도 **필수 핵심 키워드 3개 포함 여부 + 금기 오개념 단어 미포함 여부**로 부분 점수(0~100%)와 누락 키워드 힌트를 주는 채점기.
6. **메타인지 확신도 보정 (`Confidence-Weighted Rating`)**:
   - 정답 공개 직전 0.5초 동안 `확신함 / 반신반의` 여부를 반영(또는 응답 시간으로 암묵적 추론)하여, **"찍어서 맞힌 문제(Lucky Guess)"**가 `Good(3)`으로 둔갑해 수주일 뒤로 밀려나는 참사를 방지.
